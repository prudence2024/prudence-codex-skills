# 3D Web

## Purpose

Use 3D on the web when it improves the experience and can be verified across devices.

Use this skill as a capability layer. It should improve decisions, testing, and handoffs without replacing the user's specific request, project architecture, or explicit authorization boundaries.

## Boundaries

Includes:
- Three.js, React Three Fiber, Drei, WebGL concepts, scene composition, camera, lighting, materials, interaction, performance, responsive behavior, accessibility, and progressive enhancement.
- Decision criteria for when 3D is unnecessary or harmful.

Excludes:
- General design-system work covered by Design Toolkit.
- Package adoption without Package Intelligence.
