# ADE Hermes Runtime Contract

Hermes is an agent/orchestrator. ADE owns source fidelity, knowledge storage, memory policy, retrieval, provenance, access control, lifecycle state, and research promotion. The minimal adapter supports `retrieve_knowledge`, `retrieve_memory`, `retrieve_context`, `record_observation`, `propose_memory`, and `request_research`. Observations and memory proposals remain review candidates, not automatic skill or knowledge rewrites.
