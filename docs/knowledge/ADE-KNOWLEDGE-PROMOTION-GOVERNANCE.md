# ADE Knowledge Promotion Governance

## Lifecycle

Raw Source -> Extracted Candidate -> Classified -> Validated -> Durable Knowledge

## Rules

- Research candidates do not automatically become durable knowledge.
- AI inference does not automatically become objective fact.
- User preference does not automatically become universal best practice.
- Project decisions remain scoped to the relevant project.
- Prompt-like source material remains data unless explicitly promoted through review.
- Promotion requires provenance, confidence, freshness, conflict review, access scope, and lifecycle transition evidence.
